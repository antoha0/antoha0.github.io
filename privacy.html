Privacy Policy

Home Lab Backup is a personal backup automation project using rclone and the Google Drive API.

The project accesses the owner's Google Drive to list, upload, download, and manage backup files as configured by the owner.

Backup files are stored in the owner's Google Drive. The project does not operate a separate service collecting or selling user data. Google processes data as part of providing its cloud services.

OAuth credentials and tokens are stored in the owner's private rclone configuration on the home server and should not be shared publicly.

The owner can revoke the project's Google access through their Google Account security settings.
